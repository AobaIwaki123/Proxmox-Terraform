# タスク完了時のワークフロー

## コード変更後の必須チェック

### 1. フォーマット確認
```bash
terraform fmt
```
- コードの自動フォーマットを実行
- 一貫性のあるコードスタイルを維持

### 2. 構文検証
```bash
terraform validate
```
- Terraformコードの構文エラーをチェック
- 変数の型や参照の妥当性を確認

### 3. 実行計画確認
```bash
terraform plan
```
- 変更内容の事前確認
- 予期しない変更がないかチェック

## デプロイ前の最終確認

### 1. 設定値の確認
- `terraform.tfvars`の値が正しいか
- IPアドレスの重複がないか
- VMIDの重複がないか

### 2. プロバイダー設定の確認
- `provider.tf`のAPIトークンが有効か
- プロキシ設定が正しいか（必要に応じて）

### 3. 依存関係の確認
- テンプレートが存在するか
- ストレージが利用可能か
- ネットワーク設定が正しいか

## デプロイ後の確認

### 1. リソース状態確認
```bash
terraform show
```

### 2. 接続テスト
```bash
# VM/コンテナへのSSH接続テスト
ssh username@ip_address
```

### 3. ログ確認
- Proxmoxのログでエラーがないか確認
- Terraformの実行ログを確認

## エラー時の対処

### 1. 状態ファイルの問題
```bash
# 状態ファイルの確認
terraform state list
terraform state show resource_name
```

### 2. プロバイダー接続エラー
- APIトークンの有効性確認
- ネットワーク接続確認
- プロキシ設定確認

### 3. リソース作成エラー
- Proxmoxのリソース制限確認
- テンプレートの存在確認
- ストレージ容量確認

# ドキュメント管理システム

## 概要
プロジェクト全体のドキュメントを一元管理するシステム。技術的な手順書、設定方法、ベストプラクティスなどをMarkdown形式で管理。

## ディレクトリ構成
```
docs/
└── create_vm_template.md    # VMテンプレート作成手順
```

## 主要ドキュメント

### VMテンプレート作成手順 (`create_vm_template.md`)
#### 旧方式（手動）
1. Ubuntu 24.10 Cloud Imageのダウンロード
2. Proxmoxノード上でのVM作成・設定
3. Cloud-init設定
4. テンプレート変換

#### 新方式（Terraform）
- 公式Terraform Providerの手順を参考
- より自動化されたアプローチ
- 未検証のため要検証

## ドキュメント管理方針
- **形式**: Markdown (.md)
- **配置**: `/docs/` ディレクトリ
- **命名**: 機能名_目的.md
- **更新**: プロジェクト変更時に随時更新

## 参考リンク管理
- 外部リソースのリンクを適切に管理
- 古い情報と新しい情報を区別
- 検証済みと未検証を明記

## 今後の拡張予定
- 各モジュールの詳細ドキュメント
- トラブルシューティングガイド
- ベストプラクティス集
- API仕様書（WebUI用）
